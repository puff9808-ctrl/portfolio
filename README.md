## 📌 About the Project

This repository contains my personal portfolio website, designed to present my profile, projects, skills, and professional information in a clean and interactive interface.

The website is built using HTML5, CSS3, and vanilla JavaScript, focusing on responsive layouts, smooth animations, and an engaging user experience across desktop and mobile devices.

## ✨ Features

- **Responsive Design:** Adapts to different screen sizes and devices.
- **Animated Portrait:** Adds visual personality to the landing page.
- **Interactive Animations:** Includes scroll-reveal effects and visual transitions.
- **Mobile Navigation:** Provides convenient navigation on smaller screens.
- **Project Showcase:** Highlights selected projects with relevant links and details.
- **Résumé Access:** Provides access to my résumé.
- **Contact Links:** Makes it easy to connect with me.
- **Clean Interface:** Uses modern styling and structured layouts for readability.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- A modern web browser.
- Git (optional, for cloning the repository).
- Python (optional, for running a local development server).

### 1. Clone the Repository

```bash
git clone https://github.com/puff9808-ctrl/portfolio.git
```

### 2. Navigate to the Project Folder

```bash
cd portfolio
```

### 3. Run the Website

**Option A: Open directly**

Open `index.html` in your browser.

**Option B: Use a local server (recommended)**

If Python is installed, run:

```bash
python -m http.server 5500
```

Then open the following address in your browser:

```text
http://localhost:5500
```

Press `Ctrl + C` in the terminal to stop the server.

> No npm installation, build process, or backend server is required for the current static website.
